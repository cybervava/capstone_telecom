Every call, and the key it is made with

The specialists, the executor, the radio and the enquiry window reach SkyLink’s systems through one gateway, each with a key of its own. The coordinator’s two model calls go through the LLM gateway. Choose a call to see its path on the map.

Who holds which key

The gateway turns each key into a fixed set of scopes. Each program is started with only its own callers’ keys, so a fault in one cannot borrow another’s powers. The front desk holds no key at all, and the coordinator’s four keys are all read-only.

reads writes the NOC’s announcement stream

Troubleshooting needs no key: it reads only the platform’s own guide index. The simulator also accepts an admin key, which only the tests use to stage outages and failures. Source: src/mock_oss/auth.py, src/skylink_care/adapters/gateway.py, docker-compose.yml.

One turn of the coordinator

A conversation is a LangGraph thread kept in PostgreSQL. A note in its inbox starts a turn; the supervisor chooses step after step until there is nothing left to do but wait; the thread is then saved and parked until the next note.

The enquiry window: what an outside assistant may ask

care-mcp is a Model Context Protocol server over streamable HTTP at /mcp. An assistant must present a Bearer key; with no key configured the window stays shut. Every argument is typed and bounded in the tool’s declaration, so a bad one is refused before the tool runs. All assistants together may make 60 calls a minute, and every call that reaches a tool is written to the audit log.

The conversation with a customer does not go through this window. The model that reads customers’ messages has no tools at all, and that stays so (docs/adr/0003-read-only-tools-over-mcp.md).

What crosses each boundary

BoundaryWhat crosses itWhat guards it
People → the front deskMessages from customers and channels; staff’s decisionsSigned tokens with six roles. A first contact is never refused; after it, 5 new contacts a minute per caller and 20 messages a minute per conversation. A channel is capped at 600 contacts at once, then 60 a second. Someone else’s conversation looks exactly like one that does not exist.
Platform → the model providerMasked text, and for a guide answer the sections foundThe LLM gateway alone: masking by shape and by the customer’s own values, never the words of an unidentified visitor, 8 seconds, a strict form, no copy kept by OpenAI. A reading can only steer among options the evidence already allows.
Platform → SkyLink’s systemsReads by four specialists, the radio and the enquiry window; writes by the executor aloneOne key per caller with only its scopes; time limits; one retry for a read and none for a write; a circuit breaker; an Idempotency-Key on every write; every action checked again just before it is carried out.
An outside assistant → the enquiry windowFour questions and two resourcesA Bearer key, arguments bounded in the declaration, 60 calls a minute, read-only tools, nothing of a customer in or out, every call in the audit log.

Not built yet: one database account per program (today every program connects as the table owner, which could switch off the audit log’s refusal to change), proper staff sign-in (today a shared key and a typed name), more than one server, and a stronger identity check for visitors, such as a one-time code by text.
